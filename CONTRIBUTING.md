# Mitmachen

Danke, dass du GhulSuite verbessern möchtest! Fehlerberichte, Ideen und Pull Requests sind willkommen.

## Bevor du loslegst
- Lies [`PROJEKT.md`](PROJEKT.md): Aufbau, Bauen, Testen und die Regeln für Änderungen.
- Sicherheitslücken bitte **nicht** öffentlich melden, sondern über „Security → Report a vulnerability“ in diesem
  Repository (privat).

## Pull Requests
- Ein Thema pro Pull Request, mit Tests. Neue Texte auf Deutsch und Englisch.
- `cargo fmt`, Clippy und die Tests müssen durchlaufen.
