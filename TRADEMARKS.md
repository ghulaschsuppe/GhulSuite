# Name und Logo

Der Quelltext von GhulSuite ist freie Software unter der [AGPL-3.0](LICENSE). **Name und Logo sind es nicht.**

„GhulSuite“, die Bereichsnamen „GhulPass“, „GhulAuth“, „GhulDrive“ und „GhulMail“ als Produktnamen sowie das
Logo (violettes Schild mit den vier Farbstreifen) sind Kennzeichen von **Daniel Erdmann**.

**Erlaubt ohne Nachfrage**
- Über GhulSuite schreiben, es empfehlen, Anleitungen und Tests veröffentlichen.
- Unveränderte Builds aus diesem Repository weitergeben und dabei den Namen nennen.
- Paketquellen wie F-Droid dürfen die unveränderte App unter ihrem Namen anbieten.

**Nicht erlaubt ohne schriftliche Zustimmung**
- Veränderte Fassungen (Forks) unter dem Namen „GhulSuite“ oder mit dem Logo veröffentlichen.
  Ein Fork braucht einen eigenen Namen und ein eigenes Symbol – der Hinweis „basiert auf GhulSuite“ ist erwünscht.
- Den Namen oder das Logo so verwenden, dass der Eindruck einer offiziellen Version oder Unterstützung entsteht.

Fragen dazu bitte als Issue in diesem Repository.
