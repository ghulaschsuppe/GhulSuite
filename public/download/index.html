Windows 10 und 11

Installer (MSI) Portable Version (ZIP, z. B. für USB-Stick)

Prüfsumme MSI · Prüfsumme ZIP

  • Installer: installiert nur für dich (keine Administratorrechte nötig). Daten liegen in %APPDATA%\GhulSuite.
  • Portabel: ZIP entpacken (z. B. auf den USB-Stick) und GhulSuite.exe starten. Alle Daten bleiben im Ordner GhulSuite-Daten daneben, auf dem PC bleibt nichts zurück.
  • Windows SmartScreen warnt beim ersten Start, weil das Programm nicht kostenpflichtig signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
  • Security Keys: Windows zeigt ein eigenes Fenster für PIN und Berührung.
